### decision
State: observed
- Summary: Features are price, volume and index data only, computed with bars up to and including the signal day (the bar before the fill), so they are point-in-time; fundamentals, market cap and news are deliberately excluded. The label is a win (net profit after costs) by default, or whether the profit target was hit. Walk-forward trains each fold on trades that had already closed before the test window and scores the next unseen window. Probabilities are calibrated on a later time slice: isotonic with 200+ calibration rows, Platt (sigmoid) with 40-199, none below that. The stored cut-off keeps the top fraction (`--keep-top`, default 0.5) of out-of-sample probabilities. Verdicts: no skill if out-of-sample AUC is below 0.53; "do not use" if the filter did not raise average R; "unstable" if it helped in fewer than half the folds; otherwise "promising".

### Conclusion
- Does: Trains an optional second-stage filter that scores how likely each rule-generated setup is to win, validated walk-forward and calibrated, so the owner can rank or drop setups by predicted quality. It never creates signals or changes stops, targets or sizing.
- Rules: Point-in-time price/volume/index features only (`meta_model.py:58`); label win or target (`meta_model.py:113`); walk-forward trains on trades closed before each test window (`meta_model.py:189`); calibration isotonic/sigmoid/none by sample size (`meta_model.py:162`); needs `--min-train-trades` (default 100) rows to save; verdicts gate whether it is worth using (`meta_model.py:233`).
- On failure: Exits 1 without saving when there are too few rows (`screener.py:574`) or scikit-learn is missing (`screener.py:577`); `walk_forward` returns a verdict instead of raising when no fold is usable (`meta_model.py:201`).
