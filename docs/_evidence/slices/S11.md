## Supporting code

`nse_client.py` provides the NSE client used by both scripts. `_rows(js)` extracts dict records from JSON responses that may be a plain list or a dict with a `data`/`result`/`results` key (`nse_client.py:100-107`, checked). `fetch()` handles caching, rate limiting, session management and debug-dump saving (`nse_client.py:76-96`, checked). `_sess()` creates a `requests.Session` with browser-like headers and fetches the NSE home page for cookies (`nse_client.py:48-54`, checked). The three parsers (`parse_shareholding`, `parse_pledge`, `parse_announcements`) use tolerant field-name matching via `_key()` (`nse_client.py:129-138`, checked).
