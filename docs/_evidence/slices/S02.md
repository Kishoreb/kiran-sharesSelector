## Supporting code

- `fundamentals.py`: computes ROCE, ROE, debt-to-equity, interest cover, growth, P/E and PEG; evaluates the 13 rules; caches per symbol.
- `fund_weights.py`: reads rule weights from `fundamental_weights.csv`, scores passed weight over evaluated weight, labels Strong, Mixed or Weak. Used by the holdings analysis only (S04).
- `screener_in.py`: downloads and parses screener.in company pages with the standard library; keeps a 7-day cache; throttles to one request per 1.5 seconds (`screener_in.py:31`).
- `ownership.py`: promoter holding, pledge, FII and DII changes from NSE and screener.in data.
- `nse_client.py`: NSE session handling, shareholding, pledge, announcements, XBRL pledge parsing.
- `qualitative.py`: Google News headlines, keyword sentiment, optional language-model scoring (Ollama, Anthropic or FinBERT), 12 regex red-flag patterns, optional governance classifier.
